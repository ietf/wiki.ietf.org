# Background

There are circumstances where a document sent to the IESG for processing (i.e., a document put in the WG State = "Publication Requested) needs to be returned back to the WG.

A common instance of this situation is significant findings during AD or IESG review which require the WG to reconsider the approach, and re-assess consensus.

# Sending the Document Back to the WG

(1) Go to the document's page in the datatracker

(2) (If scheduled on a telechat) Set the telechat date = "not on the agenda"

(3) Set the IESG state = "I-D Exists"

(4) Set the WG state = "WG Document"

(5) Provie a comment in the History log documenting this action and the rationale

Note: performing this change change will require another WG Last Call, AD Review, and IETF Last Call.
